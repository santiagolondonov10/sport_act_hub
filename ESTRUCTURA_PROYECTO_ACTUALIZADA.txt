FLUJO DE INSTALACIÓN:

1. Copia tu API Key de OpenAI
   └─ https://platform.openai.com/api-keys

2. Crea archivo: server/.env
   └─ OPENAI_API_KEY=sk-proj-tu-clave
      API_PORT=3001

3. Inicia terminal 1:
   └─ npm run dev:server

4. Inicia terminal 2:
   └─ npm run dev

5. Abre navegador:
   └─ http://localhost:5173

6. ¡Usa el asistente!
   └─ Click en botón azul 💬 (esquina inferior derecha)
